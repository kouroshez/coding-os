↺ Continuous Feedback Loops

  • Discovery Protocol — on new actor/state/dep/constraint: record → impact → backtrack_now | record_for_later. Auto-trigger hook: track-discovery.sh.
  • Backtrack — formula outputs signal missing prereq (e.g., F5 sees unknown actor → backtrack → F2). Logged in backtrack_events (v14).
  • Anti-Paralysis Guard — counter ≥3 backtracks AND no forward progress (no new EvidenceBundle append since last backtrack) → BLOCKING advisory.
  • Recursion — if F2 Step 12 detects sub-component too large → supervisor spawns sub-session (new task_marker) starting from F1 on that component.
  • Traceability — auto at PLAN→EXECUTE boundary AND SessionEnd. Reports gaps (top w/o bottom) and orphans (bottom w/o top).
  • Intensity — light (F2.1-5 only, skip F8/F10/F11) · standard (all 11) · full (+ threat model, DR drills, zero ambiguity skips).

⚠ 10 Failure Modes

  1. Skipped F1 → F3 picks wrong stack → rework at F5
  2. F2.11 (Unknowns) not audited → F5 finds missing actor
  3. F2.7 state machine vague → F6 can't test → prod bug
  4. F3 ADRs missing → F11 reverses a forgotten decision
  5. F4 not updated during F5 → doc drift → onboarding broken
  6. F6 Layer 4 (LLM) skipped → AI feature regresses silently
  7. F8 Layer 1 auth missed on one route → audit invalid
  8. F10 Golden Signals absent → F7 has no evidence trail
  9. Anti-Paralysis violation → backtrack loop → no progress
  10. Traceability gap → orphan code (waste) or missing feature (gap)
